Rules

Landing page rules

One primary action, always “Sign in”, in navy (white on the photo band).
Content only states what the platform really does: no prices, statistics, testimonials or self-registration.
Signed out: cards and buttons lead to Sign in. Signed in: the header CTA becomes “Go to my dashboard” and cards deep-link to their page.
Header anchors scroll to sections and mark the current one; the footer repeats them; a skip link is the first focusable element.
Photo panels keep the charte’s translucent navy band: white text on navy is 9.4 : 1.
Legal links (privacy, terms) are not designed: no content was provided (TO CONFIRM).

Profile form rules

Three numbered sections on every Edit profile page: 1 Personal information (editable), 2 Account information (read-only), 3 Account & security (sensitive, own submit).
Two password behaviours, never mixed: own password = current + new + confirm; an administrator resetting another user = new + confirm only, then a confirmation dialog.
Save stays disabled until something changes; an “Unsaved changes” indicator sits next to it.
Leaving with unsaved changes opens “Discard your changes?”, with “Keep editing” as the safe first action.
Errors: inline message + icon + red border, summary alert for two or more, focus on the first invalid field.
Saved: toast (role=status), back to the read view, focus on the page title.
Mobile: Cancel and Save live in a bar fixed at the bottom of the screen.
