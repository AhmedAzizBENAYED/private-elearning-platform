Behaviour and API notes
DEV NOTE
An administrator can edit name and photo of a member. Email, role and status are shown read-only: editing them, deactivating, deleting a member or resetting a password is not designed (BACKEND GAP). The banner “You are editing the profile of another member” is always visible.
BACKEND GAP — NOT IMPLEMENTED
Editing a member’s profile, and the permission it requires (all administrators or a specific right), are not in the described backend. The 403 page and the disabled “Edit profile” button are designed for the case where the permission exists but is refused.
TO CONFIRM WITH API
Confirm what the member sees after an edit, and whether the API keeps a change history: neither is assumed.
