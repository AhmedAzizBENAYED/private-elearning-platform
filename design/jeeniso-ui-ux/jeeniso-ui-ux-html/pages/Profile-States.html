Behaviour and API notes
DEV NOTE
Editable: first name, last name and the photo. Read-only: email, role, status, creation date. “Save changes” stays disabled until a field changes. Leaving with unsaved changes (Cancel, back, browser navigation) opens the discard dialog. Errors are checked on save; two or more errors add a summary at the top and focus moves to the first invalid field. After a successful save the page returns to the read view, a toast announces “Profile updated” and focus goes to the page title.
BACKEND GAP — NOT IMPLEMENTED
Updating a profile, uploading and removing a photo are not part of the described backend. Everything on these boards is designed but not available until the endpoints exist. If photos are not supported, remove the “Photo” card and keep the initials avatar (see the admin states board).
