Handoff · accessibility & responsive

Rules the implementation must keep, mapped to WCAG 2.1 AA.

Accessibility checklist

Contrast
All text ≥ 4.5 : 1, large text and UI ≥ 3 : 1 (see DS 02 Colors).
Not colour alone
Status = icon + text + shape. Lesson state = 3 shapes + hidden text. Errors = icon + text + border weight.
Focus
Visible 3 px brand-blue ring with 2 px offset on every control.
Targets
Interactive elements ≥ 44 px (36 px small buttons only in dense desktop tables).
Forms
Programmatic labels, required marked, errors announced and linked, submit on Enter.
Language
lang attribute on <html>; copy externalised for a FR version.
Motion
prefers-reduced-motion disables transitions and skeleton shimmer; no autoplay.
Landmarks
header, nav (labelled), main, aside (course outline), footer.
Zoom / text size
Layouts reflow to 320 px and stay usable at 200 % text size.

Keyboard map

Tab / Shift+Tab
Moves through interactive elements in visual order; skip link to main content.
Enter / Space
Activates buttons and links; Space toggles play / pause in the player.
Esc
Closes modal, menu, dropdown.
← →
Tabs, segmented control, video seek (5 s).
↑ ↓
Menu and listbox navigation; reorder buttons are real buttons (no drag-only path).
F / M / K
Player: fullscreen, mute, play-pause.

Responsive behaviour

Learning page ≥ 1024
Two columns: content (fluid) + outline (400 / 340 px, sticky, own scroll).
Learning page < 1024
Stack: video → lesson info → progress → previous / next → outline. Previous / next become full-width cards on mobile.
Catalogue
3 columns ≥ 1280, 2 columns 600–1279, 1 column below.
Tables (admin)
≥ 1024 full table; 600–1023 fewer columns; < 600 cards.
Header
Desktop bar with nav; mobile bar with logo + avatar and a bottom navigation.
Modals
Centered ≥ 600; bottom-anchored sheet below 600 px.
