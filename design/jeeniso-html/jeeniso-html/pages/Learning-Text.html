Before you start

These exercises use only what you have seen in the first two modules. Take your time and write each solution in your own editor before checking the video.

Exercises

  1. Write a function greet(name) that returns a welcome message.
  2. Add a default value so that greet() works without an argument.
  3. Explain in one sentence why a variable defined inside a function is not visible outside of it.
Tip. If you get stuck, re-watch the lesson “Scope” before moving on to “Classes”.
