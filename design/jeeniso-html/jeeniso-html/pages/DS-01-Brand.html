Protective space X

Keep an empty margin X on all sides, where X ≈ 12 % of the logo width (never below 16 px). Nothing — text, borders, image edges — enters this zone.

Minimum size

The charte sets 30 mm as the smallest reproduction. On screen this is 113 px wide: never render the logo narrower, including on mobile (mobile header uses 116 px).
