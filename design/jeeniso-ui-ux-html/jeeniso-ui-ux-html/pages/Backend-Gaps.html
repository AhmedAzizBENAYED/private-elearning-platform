Backend gaps & assumptions

Everything the design needs but the described backend does not (yet) provide — nothing here was silently invented.
DEV NOTE
No endpoint is assumed. The only facts used: base /api/v1, header Authorization: Bearer <access_token>, the two roles ADMIN / MEMBER, the course lifecycle DRAFT → PUBLISHED → ARCHIVED, lesson types VIDEO / DOCUMENT / TEXT / LINK, and completion = all VIDEO lessons done.
DEV NOTE
The UI never talks to Google Drive or any storage provider and never displays its name or URLs. Video and document links are whatever the API returns; the front end stays independent of the storage decision.
