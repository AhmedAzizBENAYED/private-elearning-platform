DEV NOTE
Brand blue #3594D6 = 3.30 : 1 on white. It passes for large text (≥ 24 px, or ≥ 18.66 px bold), icons and graphic objects — never for body text or button labels. Small text, links and buttons use navy #1A4A6B (9.4 : 1), an official secondary colour, so the interface stays on-brand and AA.
DEV NOTE
Light gray #908F8F = 3.2 : 1: decorative rules and form-control borders only, never text. Disabled controls are exempt but keep a text alternative.
